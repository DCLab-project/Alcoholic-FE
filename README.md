# FE

## 1. 저장소 목적
이 저장소는 **술안주 추천 AI 냉장고의 사용자 디스플레이 UI**를 담당합니다.

프로젝트 계획서 기준으로 FE는 다음 화면 흐름을 중심으로 구성됩니다.
- 메인 화면
- 현재 재고 화면
- 추천 결과 화면
- 추천 상세 화면
- 인식 보정 화면

## 2. 주요 역할
- 사용자 접근 감지 후 주류 스캔 대기 화면 제공
- 현재 냉장고 재고 목록 및 수량 시각화
- 인식된 주류에 맞는 안주 후보 3종 표시
- 선택한 안주의 상세 레시피, 추천 이유, 부족 재료 안내
- 인식 오류 발생 시 사용자 보정 UI 제공

## 3. 화면 구조 권장안
```bash
src/
  components/
  pages/
    Main/
    Inventory/
    Recommendation/
    RecommendationDetail/
    Correction/
  hooks/
  services/
  store/
  types/
  utils/
```

## 4. 개발 원칙
- 사용자는 빠르게 현재 재고와 추천 결과를 이해할 수 있어야 합니다.
- 추천 화면은 **후보 3개 비교가 쉬운 구조**를 우선합니다.
- 상세 화면은 **추천 이유 / 부족 재료 / 조리 순서**가 분리되어야 합니다.
- 보정 화면은 최소 입력으로 수정 가능해야 합니다.
- UI 문구는 팀에서 별도 합의가 없으면 한국어를 기본으로 합니다.

## 5. 상태 관리 포인트
FE는 아래 상태를 명확히 구분해 관리합니다.
- 현재 재고 상태
- 마지막 인식 주류 상태
- 추천 후보 목록
- 선택된 후보 상세 정보
- 보정 요청 상태

## 6. 실행 방법
현재 PDF에는 FE 기술 스택 및 실제 실행 명령이 명시되어 있지 않으므로, 아래는 **초기 템플릿 예시**입니다.
프로젝트 세팅 후 실제 명령으로 수정해주세요.

```bash
# example
npm install
npm run dev
```

## 7. 환경 변수 예시
실제 값과 키 이름은 프로젝트 초기 세팅 후 확정합니다.

```bash
VITE_API_BASE_URL=
VITE_APP_NAME=
```

## 8. FE에서 특히 중요하게 볼 것
- 로딩/빈 상태/에러 상태 표시
- 추천 결과 재조회 UX
- 인식 보정 후 화면 복귀 흐름
- 디스플레이 환경을 고려한 가독성
